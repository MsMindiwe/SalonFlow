SalonFlow
Salon Appointment and Queue Management System

SalonFlow is an Object-Oriented Programming (OOP) student project designed to help small salons manage customer appointments, stylist availability, and waiting queues.

Project Objectives

    Register and manage customer information.

    Create, view, update, and cancel appointments.

    Maintain stylist information and availability.

    Assign customers to available stylists.

    Manage walk-in customers in a waiting queue.

    Track service status: waiting, being served, or completed.

Proposed Technologies

    Programming language: Java

    User interface: Java Swing

    Development environment: NetBeans or IntelliJ IDEA

    Data storage: MySQL or file-based storage, depending on project requirements

Object-Oriented Design

The proposed classes are Person, Customer, Stylist, Appointment, QueueManager, and Salon. The project will demonstrate encapsulation, inheritance, polymorphism, and abstraction.
Scope and Limitations

The initial version is intended for salon staff in small salons. Online payments, customer accounts, SMS notifications, and online booking are outside its scope.
